# Embryo CAD Script

Embryo CAD Script is Embryo-Zero's fork of [build123d](https://github.com/gumyr/build123d) (8111522, commit 8111522). It does 3D design written as Python code.

- Our changes live on the `embryo` branch. The original license files (LICENSE, NOTICE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
